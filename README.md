# Joucho actor — Well-Becoming experience signals

Canonical repository: `etzhayyim/actor-joucho`.

Joucho is a signal-producing organ of the Tamaki artificial organism. It derives
advisory Well-Becoming observations about places, meals, products, buildings,
and services; it is not an independent adjudicator or authority.

Its scores must never become a score of a person, an adherent rank, an access or
benefit decision, or a substitute for Tamaki governance. Derived signals remain
reviewable evidence and all external effects stay behind the surrounding human,
Council, capability, and audit boundaries.

The stable actor identity remains `did:web:etzhayyim.com:actor:joucho`.

See `CLAUDE.md` and `manifest.edn` for the existing runtime contract.
